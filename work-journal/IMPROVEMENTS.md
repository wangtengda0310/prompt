# work-journal skill 改进计划

## 来源：iteration-1 测试对比（2026-04-01）

### 1. 纪要格式优化

**现状**：with-skill 输出格式规范但略显刻板，without-skill 输出更灵活（额外包含"未提交变更"章节）。

**改进方向**：
- 增加"未提交变更"章节，记录进行中的工作（从 git status 提取）
- 子模块提交记录：当权限允许时，进入各子模块目录获取详细提交
- 整合设计文档内容：纪要中引用关键设计决策，而非只列提交

### 2. 周报格式优化

**现状**：
- with-skill：按类别分组 + 统计表（简洁但缺乏细节）
- without-skill：逐条提交记录表（详细但缺乏统计视角）

**改进方向**：**两者结合**
- 保留分类总结（按工作类别分组）
- 保留提交统计表（模块维度）
- 新增"详细提交记录"章节（逐条列出所有提交，按日期排序）
- 格式参考：
  ```
  ## 本周工作总结（分类归纳）
  ...
  ## 本周提交统计（模块维度）
  | 模块 | 提交数 | 主要变更 |
  ...
  ## 详细提交记录（逐条）
  | 日期 | 提交 | 说明 |
  ...
  ## 下周计划
  ...
  ## 风险与问题
  ...
  ```

### 3. 其他改进项

- 晨会标记：纪要中自动标注当天是否为晨会日
- 性能优化：减少不必要的 tool uses（当前 with-skill 耗时 ~175s，baseline ~110-196s）
- 子模块 git log：提供权限或脚本辅助获取子模块提交记录

### ~~4. 历史对话回顾~~ (已完成 2026-04-01)

已实现两层回顾机制：
- 第一层：轻量回顾 — 读取 `~/.claude/history.jsonl` 获取用户输入
- 第二层：深度回顾 — `claude -p "..." --resume <session-id>` 唤醒历史会话
